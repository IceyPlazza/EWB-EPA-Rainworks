# Electrcial PCB Version Control

In the past, the Rainworks PCB utilized a website called EasyEDA for version control. This website, while working, is too basic compared to 
professional use cases and does not use the typical version control structure of (some) companies.

As a result, we will be transitioning to KiCad. If you are new, do not worry about the logistics of this transition.

For all members, please install KiCad. This is a free application that works on both Mac and Windows, and is used by many Vanderbilt 
professors and in coursework. While it is not used in all industry enviroments, it is closer to what is done in industry and is a decent representation.

https://www.kicad.org/download/

PCB versions will be maintained here. If you are modifying the PCB, please submit a PR here for Vivian or Mariami to review. Feel free to look 
through the design in KiCad as well and play around with it as much as you would like! That is the best way to learn the tool :)

If you have any questions, contact Vivian Zeru (vivian.zeru@vanderbilt.edu).
